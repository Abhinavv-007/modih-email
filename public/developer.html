API Reference
Use your API key in the X-API-Key header for programmatic access.
Create Inbox
POST https://modih.in/api/inbox
Creates a new disposable inbox. Returns the inbox details including owner_token for subsequent message reads.
curl -X POST https://modih.in/api/inbox \ -H "X-API-Key: mdh_your_key_here" \ -H "X-Browser-Token: any-stable-uuid" \ -H "Content-Type: application/json" \ -d '{"prefix": "myapp-test"}'
{ "id": "abc123...", "email": "myapp-test@modih.in", "owner_token": "token-for-reading-messages", "created_at": 1711234567, "expires_at": 1711839367, "plan": "developer" }
Read Messages
GET https://modih.in/api/messages?inbox_id={id}
Returns all messages for the inbox. Requires X-Owner-Token from inbox creation. Each call counts as 1 read against your monthly quota.
curl https://modih.in/api/messages?inbox_id=abc123 \ -H "X-API-Key: mdh_your_key_here" \ -H "X-Owner-Token: token-from-inbox-creation"
{ "inbox": { "id": "...", "email": "...", "expires_at": ... }, "messages": [ { "id": "msg-id", "from_address": "sender@example.com", "subject": "Welcome!", "body_text": "Hello...", "body_html": "<p>Hello...</p>", "received_at": 1711234999 } ] }
Delete Inbox
DELETE https://modih.in/api/inbox?id={id}
Deletes an inbox and all its messages. Requires X-Owner-Token header.
curl -X DELETE "https://modih.in/api/inbox?id=abc123" \ -H "X-Owner-Token: token-from-inbox-creation"
Usage Stats
GET https://modih.in/api/developer/usage
Returns your current monthly API usage against plan limits.
curl https://modih.in/api/developer/usage \ -H "Authorization: Bearer <firebase-id-token>"
