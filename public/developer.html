✦ Documentation

API reference.

Pass your key in the X-API-Key header. Owner tokens from inbox creation are still required to read messages.

POST /api/inbox

Create a disposable inbox. Returns owner_token for subsequent message reads. Custom prefix requires Developer plan.

curl -X POST https://modih.in/api/inbox \ -H "X-API-Key: modih-your_key_here" \ -H "X-Browser-Token: any-stable-uuid" \ -H "Content-Type: application/json" \ -d '{"prefix": "myapp-signup"}'
{ "id": "abc1def2ghi3jkl4", "email": "myapp-signup@modih.in", "owner_token": "use-this-to-read-messages", "created_at": 1711234567, "expires_at": 1711839367, "plan": "developer" }
GET /api/messages?inbox_id={id}

Fetch all messages in an inbox. Each call counts as 1 read against your 50k/month quota. Requires the owner_token from inbox creation.

curl "https://modih.in/api/messages?inbox_id=abc1def2ghi3jkl4" \ -H "X-API-Key: modih-your_key_here" \ -H "X-Owner-Token: use-this-to-read-messages"
{ "inbox": { "id": "...", "email": "myapp-signup@modih.in", "expires_at": 1711839367 }, "messages": [ { "id": "msg-id", "from_address": "verify@example.com", "subject": "Your verification code", "body_text": "Your OTP is 482910", "body_html": "<p>Your OTP is <strong>482910</strong></p>", "received_at": 1711234999 } ] }
DELETE /api/inbox?id={id}

Permanently delete an inbox and all its messages. Requires X-Owner-Token header. No API key needed for deletion.

curl -X DELETE "https://modih.in/api/inbox?id=abc1def2ghi3jkl4" \ -H "X-Owner-Token: use-this-to-read-messages"
