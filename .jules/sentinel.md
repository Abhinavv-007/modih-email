## 2024-05-06 - Add Security Headers
**Vulnerability:** Missing basic security headers like HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, and Content-Security-Policy.
**Learning:** For Cloudflare Pages projects, standard security headers can be enforced by adding a `_headers` file in the static build output directory (`public/_headers` in this case).
**Prevention:** Include a standard `_headers` file when setting up new Cloudflare Pages projects to enforce baseline defense-in-depth protections.
## 2026-05-22 - Secure PRNG Replacement\n**Vulnerability:** Weak pseudo-random number generators (Math.random()) were used for generating UUID fallbacks and MIME boundaries, leading to potential predictability.\n**Learning:** Cryptographically secure replacements like crypto.getRandomValues() should always be used to generate IDs or boundary markers, particularly when these components are related to security protocols or avoiding collisions.\n**Prevention:** Avoid Math.random() in favor of crypto interfaces anywhere randomness needs to be unguessable.
